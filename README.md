# Python Quiz Game Project

This project involves the development of an interactive quiz game in Python. The game presents multiple-choice questions to the user, tracks their score, and provides feedback on their performance. The key features of the project include:

- Question Bank: A set of predefined questions with multiple-choice answers.

- User Interaction: Prompts the user to select an answer and provides immediate feedback.

- Score Tracking: Keeps track of the user's correct and incorrect answers.

- Game Loop: Continues to present questions until the user chooses to exit the game.

## Key Features

- Randomized Questions: Questions are randomly selected from the question bank for each game session.

- User-Friendly Interface: Simple and intuitive command-line interface for easy interaction.

- Real-Time Feedback: Provides instant feedback on the user's answer and displays the correct answer if the user is wrong.

- Score Summary: Displays the user's final score and performance summary at the end of the game.

## Technologies Used

- Python: The core programming language used to develop the game.

- Libraries: Utilizes standard Python libraries for randomization and input handling.
